# 미로찾기

별똥별이 떨어진 밤, 미로에 갇힌 가족 여섯을 구하는 웹 게임이에요. 등급이 오를수록 화면에 보이는 미로가 좁아져요.

| 등급 | 구할 가족 | 미로 크기 (1단계 → 50단계) | 화면에 보이는 미로 넓이 |
|---|---|---|---|
| 초보 | 형 | 5×5 → 10×10 | 100% |
| 중급 | 누나 | 10×10 → 15×15 | 50% |
| 고급 | 남동생 | 15×15 → 20×20 | 30% |
| 특급 | 여동생 | 20×20 → 25×25 | 15% |
| 신 | 아빠 | 25×25 → 30×30 | 5% |
| 우주 (숨겨진 곳) | 엄마 | 50×50 미로 1개 | 5% |

- 한 등급의 50단계를 모두 깨면 가족 한 명을 구출하고 다음 등급이 열려요. 현재 단계를 깨야 다음 단계가 열려요.
- 신을 끝내면 숨어 있던 우주 미로가 나타나요. 엄마를 구하면 온 가족이 다시 만나요.
- 화면을 밀면 그 방향으로 곧게 가다가 벽 · 모퉁이 · 갈림길에서 멈춰요. 키보드 방향키도 돼요.
- 지나온 길(발자국)은 1초 안에 사라져요.
- 진행과 최고 기록은 기기(브라우저)에만 저장해요.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # dist/ 에 빌드
```

## 미로 데이터

미로 251개(5등급 × 50단계 + 우주 1개)는 `src/data/maps.json`에 미리 만들어 두었어요. 고정 시드로 만들어서 다시 만들어도 같아요.

```bash
npm run maps
```

`main` 브랜치에 올리면 GitHub Actions가 테스트 · 빌드한 뒤 GitHub Pages에 올려요.
