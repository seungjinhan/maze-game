# 미로찾기

50단계 미로를 5개 등급으로 차례로 푸는 웹 게임이에요. 등급이 오를수록 화면에 보이는 미로가 좁아져요.

| 등급 | 화면에 보이는 미로 넓이 |
|---|---|
| 초보 | 100% |
| 중급 | 50% |
| 고급 | 30% |
| 특급 | 15% |
| 신 | 5% |

- 한 등급의 50단계를 모두 깨면 다음 등급이 열려요. 현재 단계를 깨야 다음 단계가 열려요.
- 화면을 밀면 그 방향으로 곧게 가다가 벽 · 모퉁이 · 갈림길에서 멈춰요. 키보드 방향키도 돼요.
- 지나온 길은 1초 안에 사라져요.
- 진행과 최고 기록은 기기(브라우저)에만 저장해요.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # dist/ 에 빌드
```

## 미로 데이터

미로 250개(5등급 × 50단계)는 `src/data/maps.json`에 미리 만들어 두었어요. 고정 시드로 만들어서 다시 만들어도 같아요.

```bash
npm run maps
```

`main` 브랜치에 올리면 GitHub Actions가 테스트 · 빌드한 뒤 GitHub Pages에 올려요.
